# HQ

このクラスの本部です。参加登録もフラグの提出も、すべて **Issue** で行います。

> **このリポジトリは公開されています。** 本名、学校名、そのほか個人的なことは絶対に書かないでください。

## はじめに

1. [New issue](https://github.com/kwaka1208/quests-hq-2025/issues/new/choose) を開き、**Join HQ** を選びます。
2. 数秒待つと、bot が Issue に返信します。

## クエスト（リーディングとライティング）

クエストは [quests-2025](https://github.com/kwaka1208/quests-2025) にあります。
その README を読んで、**fork** のしかたと、毎週新しいクエストを受け取る方法を覚えましょう。
読むクエストも書くクエストも、クリアしたら、ここで **Submit a Flag** のフォームを使ってフラグを提出します。

正解したフラグは、Issue に `cleared` のラベルが付いて残ります。
自分の記録は、[自分がクリアした Issue の一覧](https://github.com/kwaka1208/quests-hq-2025/issues?q=is%3Aissue+author%3A%40me+label%3Acleared) で見られます。
順位や点数はありません。ほかの人と競うのではなく、自分のペースで進めましょう。

## オープンソース

このクラスのリポジトリは、オープンソースのプロジェクトです。誰でも貢献できます。

- **quests-2025**：誤字、リンク切れ、わかりにくい文を直す。
  `good first issue` のラベルがついた Issue から始めましょう

慣れてきたら、実在のオープンソースにも挑戦してみましょう！ プルリクエストを送る**前に**、
先生に見てもらってください。
