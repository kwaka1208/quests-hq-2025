# HQ

開発の現場では、毎日たくさんの文書を読み、書いています。README、エラーメッセージ、`--help` の表示、Issue、プルリクエストの説明。どれも、エンジニアが仕事で使う大事な文書です。

ここでは、それをゲームのように体験します。あなたは架空のソフトウェア会社 **Northwind** の新入社員です。先輩に案内されながら、会社の仕事を**クエスト**として1つずつ片づけていきます。

> **このリポジトリは公開されています。** 本名、学校や会社の名前、そのほか個人的なことは絶対に書かないでください。名前はハンドルネームを使います。

## 本部と現場

クエストでは、GitHub の2つのリポジトリを使います。

- **本部**（今見ている HQ）は、**クエストの受付と、進み具合の記録**の場所です。ここで参加を申し込み、クエストを終えたら結果を届けます。届けた結果は記録として残ります
- **現場**（[Quests](https://github.com/kwaka1208/quests-2025)）は、**クエストを実際に体験する場所**です。Northwind の仕事の現場で、毎回ここに新しいクエストが届きます。文書を読んだり書いたりするのは、すべてこちらです

| リポジトリ | 役割 | ここですること |
|---|---|---|
| **本部**（HQ） | クエストの受付と、進み具合の記録 | 参加登録をする。クリアしたらフラグを提出する。自分の記録を見る |
| **現場**（[Quests](https://github.com/kwaka1208/quests-2025)） | クエストを実際に体験する場所 | fork して、自分の Codespaces でクエストを解く。プルリクエストも出す |

## 現場で体験するクエスト

クエストには2つの種類があります。

- **読むクエスト**：現場の文書を読んで、答えを探します。全部を訳す必要はありません。見出しを見て、必要なところを探して読みます
- **書くクエスト**：会社の仕事として、文書を英語で書きます。読む人に伝わるかどうかを、チェックのプログラムが確かめます

どちらも、すべてのステージに答えると**フラグ**（`FLAG{...}` の形の文字列）がもらえます。フラグが、クエストを終えたしるしです。あなたの GitHub ID から作られるので、ほかの人のフラグを写しても通りません。

クエストを進めながら、fork、Issue、プルリクエストなど、オープンソースの開発と同じやり方も覚えていきます。

## 進め方

1. **本部で受付**：**Join HQ** で参加登録をする（下の「はじめに：参加登録」）
2. **現場へ行く**：[Quests](https://github.com/kwaka1208/quests-2025) を fork し、その README のとおりに Codespaces で開く
3. **現場でクエストを解く**：クエストのフォルダの README を読み、`quest.py` の問いに答えてフラグを手に入れる
4. **本部に届ける**：**Submit a Flag** でフラグを提出する。正解すると記録に残る

2〜4 を、クエストのたびにくり返します。

## はじめに：参加登録

本部の受付は、参加登録もフラグの提出も、**Issue** のフォームで行います。フォームに書いて送ると、bot が数秒で返信します。

1. [New issue](https://github.com/kwaka1208/quests-hq-2025/issues/new/choose) を開き、**Join HQ** を選びます。
2. ハンドルネームを書いて送ります。
3. 数秒待つと、bot が Issue に返信します。登録できたら、`member` のラベルが付きます。

登録できたら、現場の [Quests](https://github.com/kwaka1208/quests-2025) に進み、その README を読みましょう。

## フラグの提出と記録

クエストを終えたら、[New issue](https://github.com/kwaka1208/quests-hq-2025/issues/new/choose) で **Submit a Flag** のフォームを使ってフラグを提出します。

正解したフラグは、Issue に `cleared` のラベルが付いて残ります。これが、あなたの進み具合の記録です。
自分の記録は、[自分がクリアした Issue の一覧](https://github.com/kwaka1208/quests-hq-2025/issues?q=is%3Aissue+author%3A%40me+label%3Acleared) で見られます。
順位や点数はありません。ほかの人と競うのではなく、自分のペースで進めましょう。
